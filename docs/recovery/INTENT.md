# REC-P02 — Intent Reconstruction

**What Fault Lines is (from `devpost/scope.md`, `prd.md`, `spec.md` — all `status: approved`, coherent):**
A misconception map for teachers. Paste a class's written answers to ONE question (one per line, names removed, ~60) → one batched analysis groups answers by underlying *belief* (not mark), names each belief, ranks by exam risk, shows verbatim student quotes as evidence, gives a ~5-minute reteach card + follow-up diagnostic per belief, exports a one-page plan. Vague answers go to an honest "Not sure — needs your eyes" bucket; nothing is hallucinated. No accounts/DB/persistence. Geological-survey aesthetic (paper `#F4F1EA`, ink, rust, slate; Fraunces + grotesque; strata bands, single 900ms reveal). Cached example classroom = zero-network demo safety net. Provider-agnostic LLM interface, mock default, real adapter env-gated.

**Where work stopped:** The scaffold was committed in one shot as a hackathon POC. The stopping point is precise: the server half was never finished (`BodySchema` referenced but never defined — `/api/analyze` cannot execute), so the app only ever "worked" via the client's silent in-browser mock fallback and the cached example. Everything downstream of a real analysis (question context, verbatim-quote guarantees, unsure detail, share links, print) is half-wired. Docs (PRD/spec) describe components (`InputPanel`, `BandDetail`, `ExportPlan`, `lib/validate.ts`, `lib/llm/real.ts`) that were never created.

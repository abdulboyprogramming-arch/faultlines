# Presentation assets

Pitch material for the Devpost entry. Everything here is documentation, not app code.

| File | What it is |
|---|---|
| `Fault-Lines.pdf` | The exported deck (10 slides, 16:9). Generated in Gamma from `PROMPT.md`, screenshots added by hand, exported to PDF. 3.7 MB — the source of truth for what was submitted. |
| `PROMPT.md` | The Gamma prompt pack: settings, custom theme, 12-card outline, copy blocks. Re-run it to regenerate or restyle the deck. |
| `README.md` | This index. |

**Regenerating:** follow `PROMPT.md` §0 settings, paste the Route A prompt or the Route B outline,
apply the palette, drop in the screenshots listed in the outline, then export 16:9 PDF as
`Fault-Lines.pdf` (same filename so links keep working).

**Editing text:** export PPTX from Gamma instead of PDF — editing a PDF deck breaks the layout.

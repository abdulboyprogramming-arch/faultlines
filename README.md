# Fault Lines

See what your class actually misunderstands. For teachers marking written answers.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000. Mock mode works with no API key.

## Environment
Copy `.env.example` to `.env.local`. Set `LLM_PROVIDER=mock` (default) or a real provider plus key.

## Build
```bash
npm run build
npm run lint
```
